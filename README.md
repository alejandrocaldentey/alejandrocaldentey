## How I build

Every repo here is an **architecture case study**, not a demo:

- **Real public data** — live ingestion from public APIs (FAO, World Bank, Eurostat, ENTSO-E, Open-Meteo), never files committed to the repo.
- **Decisions on record** — every significant choice has an [ADR](https://adr.github.io/): options considered, the one chosen, why, and when I would revisit it.
- **Cost on the table** — each repo estimates the monthly cost of every process and tool across three scenarios: *Demo*, *SME* and *Enterprise*.
- **Runs, not slides** — green CI, reproducible in minutes, results linked from the README.

AI-assisted build; architecture, decisions and review are mine.
